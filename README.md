# Dressed to Major?

COMP1110 Group 65 presentation exploring clothing colour across four HKU faculties.

Open the published GitHub Pages site to view the interactive presentation.

## Presentation controls

- Arrow keys: move between slides
- F: full screen
- N: speaker notes
- O: overview and backup slides
- M: pause ambient motion

The presentation contains 15 main slides and four backup slides. The garment is an illustrative 3D model; research graphs contain aggregate project results. No participant photographs or raw participant data are included.
